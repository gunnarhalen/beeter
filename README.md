# Beeter

Nerd and Geek social network and dating site.

## Setup

### Prerequisites
- Node.js
- npm

### Installation

Install project dependencies:

```bash
npm install
```

Note: The package.json references `index.js` as the main entry point, but the actual server file is `server.js`. To run the project, use `node server.js`.

## Usage

### How to Run

Start the server:

```bash
node server.js
```

### Access the Application

Open your browser and navigate to:

```
http://localhost:3000/
```

### Available Routes

- `/` - Home page
- `/entrar` - Login page
- `/cadastrar` - Sign up page
- `/explorar` - Explore page
- `/perfil` - Profile page
- `/favoritos` - Favorites page
